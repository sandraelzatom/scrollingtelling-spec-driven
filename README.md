# Spec-Driven Scrollytelling Project 🚀

This project is a demonstration of **Scrollytelling** techniques implemented through **Spec-Driven Development**. By defining technical specifications before prompting the AI, I was able to build a performant, narrative-driven experience using only HTML and CSS animations—no external image assets required.

## 🛠 The Process: Spec-Driven Development
Following the methodology outlined by P. Williams, this project focused on "compressing" senior engineering workflows. Instead of iterative guessing, I used a structured spec to guide the AI output:

1.  **Requirement Definition:** Established a 100vh "Slide" architecture using CSS Scroll Snap for a high-end presentation feel.
2.  **Asset-Light Logic:** Specifically chose to replace heavy image files with CSS-native animations (`keyframes`, `transforms`, and `transitions`) to prioritize load speed and code cleanliness.
3.  **State Management:** Defined specific trigger points for progress bars and visual transitions to ensure the narrative flow remained consistent across different screen sizes.

## ✨ Key Features
* **CSS Scroll Snapping:** Smooth, app-like transitions between story segments.
* **Pure CSS Animations:** * *Pulse Engines:* Using `box-shadow` expansion for focal points.
    * *Dynamic Wireframing:* Procedural line growth representing the "spec" phase.
    * *Orbital Rotations:* High-performance GPU-accelerated transforms.
* **Responsive Narrative:** A mobile-first approach to scrollytelling.
